<objective>
## Goal
Bangun fondasi Framer design system di ReKal — ganti semua token warna, font, dan CSS primitif lama (glass-panel slate theme) dengan Framer's black canvas system, sehingga fase berikutnya (08-10) bisa langsung membangun di atas fondasi yang konsisten.

## Purpose
Design system adalah lapisan paling bawah. Jika token dan primitif sudah benar, fase UI berikutnya tinggal menulis class — tidak perlu inline style atau override. Tanpa fase ini, setiap fase berikutnya akan inconsistent dan hard to maintain.

## Output
- `index.html` — Inter Variable font dengan OpenType features
- `tailwind.config.js` — Framer color tokens menggantikan slate/primary theme
- `src/index.css` — Semua komponen primitif diwrite ulang: body canvas, surface cards, pill buttons, Framer input, page utilities
</objective>
