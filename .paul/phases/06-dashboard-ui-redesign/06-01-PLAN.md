<objective>
## Goal
Generate ulang tampilan Desktop Dashboard dari awal menggunakan output MCP stitch sebagai panduan desain, lalu implementasikan di Dashboard.jsx — lebih polished, modern, informatif. Mobile tidak berubah.

## Purpose
Dashboard saat ini di desktop hanya memperlebar layout mobile. Dengan stitch, kita bisa menghasilkan UI desktop yang benar-benar dirancang untuk lebar layar penuh: data density lebih tinggi, hierarchy visual lebih jelas, dan secara visual lebih profesional.

## Output
Dashboard.jsx dengan desktop UI baru mengikuti output stitch. Mobile single-column tetap identik.
</objective>
