<objective>
## Goal
Tambahkan desktop layout (sidebar kiri + konten lebar) yang aktif otomatis saat lebar layar ≥ 1024px, tanpa mengubah satu baris pun kode mobile yang sudah ada.

## Purpose
Aplikasi ReKal saat ini mobile-only (max-w-lg, BottomNav). Di layar desktop, tampilan terlihat sempit dan navigasi tidak optimal. Phase ini menambahkan web mode yang proper — sidebar navigasi di kiri, konten mengisi sisa layar — menggunakan strategi Layout Wrapper Swap sehingga mobile path tetap identik.

## Output
- `src/hooks/useIsDesktop.js` — viewport detection hook
- `src/components/SidebarNav.jsx` — sidebar navigation (pengganti BottomNav di desktop)
- `src/components/WebLayout.jsx` — wrapper layout desktop (sidebar + konten)
- `src/App.jsx` — diubah untuk switch antara AppLayout (mobile) dan WebLayout (desktop)
</objective>

<task type="auto">
  <name>Task 1: Buat useIsDesktop hook + SidebarNav + WebLayout</name>
  <files>src/hooks/useIsDesktop.js, src/components/SidebarNav.jsx, src/components/WebLayout.jsx</files>
  <action>
    **1. src/hooks/useIsDesktop.js**
    Hook sederhana berbasis window.matchMedia untuk deteksi viewport:
    - Initial state: `window.innerWidth >= 1024` (sync, tidak pakai undefined)
    - Subscribe ke `matchMedia('(min-width: 1024px)')` change event
    - Cleanup listener di useEffect return
    - Return boolean `isDesktop`
    - Gunakan `useState` + `useEffect` dari React

    **2. src/components/SidebarNav.jsx**
    Sidebar navigasi desktop, mengandung item yang SAMA dengan BottomNav:
    - 4 item: Dashboard (/), Material (/materials), Produk (/products), Simulasi (/price-simulation)
    - Icon: LayoutDashboard, Package, ShoppingBag, Calculator (dari lucide-react — sama dengan BottomNav)
    - Layout: fixed kiri, full height (`fixed left-0 top-0 h-full`), lebar 240px (`w-60`)
    - Background: `bg-slate-900/95 backdrop-blur-xl border-r border-slate-800` (konsisten dengan BottomNav)
    - Setiap item: flex row, icon (w-5 h-5) + label teks, padding `px-4 py-3`, rounded-xl
    - Active state: `text-primary-400 bg-slate-800` | Inactive: `text-slate-400 hover:text-slate-200 hover:bg-slate-800/50`
    - Gunakan NavLink dari react-router-dom (sama dengan BottomNav)
    - Logo/title di atas: "ReKal" dengan ikon kecil atau teks saja

    **3. src/components/WebLayout.jsx**
    Wrapper layout untuk desktop:
    - Import SidebarNav
    - Struktur: `div flex min-h-screen` → SidebarNav di kiri (w-60 fixed) + main di kanan
    - Main area: `ml-60` (margin kiri = lebar sidebar) + `min-h-screen bg-slate-950`
    - Konten: `{children}` tanpa max-width restriction (biarkan page container yang atur, atau beri `px-6 py-6`)
    - Jangan tambahkan max-w-lg — biarkan konten lebih lebar dari mobile
  </action>
  <verify>
    File terbuat di path yang benar. Tidak ada error import. SidebarNav menggunakan komponen dan icon yang sudah ada (lucide-react, react-router-dom).
  </verify>

</task>
