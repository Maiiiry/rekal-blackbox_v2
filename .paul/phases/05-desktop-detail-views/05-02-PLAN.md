<objective>
## Goal
Tambahkan two-column desktop layout di ProductForm — kolom kiri sticky berisi form input utama (foto, nama/deskripsi, parameters), kolom kanan berisi Material Usage Calculator + BoM + Calculation Preview + tombol submit.

## Purpose
ProductForm adalah halaman terpanjang di app. Di desktop, single-column memaksa user scroll jauh antara input parameter dan hasil preview. Two-column menempatkan input dan preview side-by-side sehingga feedback kalkulasi langsung terlihat saat user mengisi BoM.

## Output
ProductForm.jsx dengan `lg:flex` wrapper di dalam `<form>` — mobile single-column tidak berubah.
</objective>
