<objective>
## Goal
Tambahkan two-column desktop layout di PriceSimulation — kolom kiri sticky berisi Product Selection + Parameters + BoM, kolom kanan berisi Calculation Results. Sticky result bar disembunyikan di desktop (lg:hidden) karena results sudah visible di kolom kanan.

## Purpose
PriceSimulation adalah halaman "input + output" — user mengisi kiri, lihat hasil di kanan secara real-time. Di mobile, sticky bar diperlukan karena results ada di bawah fold. Di desktop two-column, results selalu visible sehingga sticky bar menjadi redundant.

## Output
PriceSimulation.jsx dengan two-column wrapper dan sticky bar lg:hidden.
</objective>
