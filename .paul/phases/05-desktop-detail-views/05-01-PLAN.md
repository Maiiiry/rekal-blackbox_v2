## Goal
Tambah two-column desktop layout di ProductDetail — gallery + nama produk di kiri (sticky), semua detail harga/BoM/chart di kanan — memanfaatkan lebar layar penuh di ≥1024px.

## Output
`src/pages/ProductDetail.jsx` — wrapper `lg:flex` dengan left column sticky (gallery+nama) dan right column scrollable (harga+BoM+chart+parameter).
</objective>
