## Goal
Tambahkan table layout untuk halaman Categories dan Materials di desktop (≥ 1024px) — menggantikan tampilan card list yang sempit dengan tabel yang informatif dan memanfaatkan lebar layar.

## Purpose
Categories dan Materials adalah halaman data management dengan pola yang serupa — keduanya cocok menjadi tabel di desktop. Dengan `lg:hidden`/`hidden lg:table` approach, mobile card layout tidak diubah sama sekali.

## Output
- `Categories.jsx` — tambah desktop table view (tersembunyi di mobile)
- `Materials.jsx` — tambah desktop table view (tersembunyi di mobile)
</objective>

       ```jsx
             </tr>
           </thead>
           <tbody className="divide-y divide-slate-800/50">
             {filteredCategories.map(category => {
               const materialCount = getMaterialCount(category.id)
               const hasMaterials = materialCount > 0
               return (
                 <tr key={category.id} className="hover:bg-slate-800/30 transition-colors">
                   <td className="py-3 pl-2">
                     <div className="flex items-center gap-3">
                       <div className="w-8 h-8 rounded-lg bg-primary-500/20 flex items-center justify-center flex-shrink-0">
                         <Layers className="w-4 h-4 text-primary-400" />
                       </div>
                       <span className="font-medium text-white">{category.name}</span>
                     </div>
                   </td>
                   <td className="py-3">
                     {hasMaterials ? (
                       <span className="badge-primary bg-accent-amber/20 text-accent-amber border-accent-amber/30">
                         <Link className="w-3 h-3 mr-1" />
                         {materialCount} material
                       </span>
                     ) : (
                       <span className="text-slate-500 text-sm">0 material</span>
                     )}
                   </td>
                   <td className="py-3 pr-2">
                     <div className="flex gap-2 justify-end">
                       <button
                         onClick={() => openModal(category)}
                         className="p-2 text-slate-400 hover:text-primary-400 hover:bg-primary-500/10 rounded-lg transition-colors"
                       >
                         <Edit2 className="w-4 h-4" />
                       </button>
                       <button
                         onClick={() => handleDelete(category.id)}
                         disabled={deletingId === category.id || hasMaterials}
                         title={hasMaterials ? `Kategori memiliki ${materialCount} material` : 'Hapus kategori'}
                         className="p-2 text-slate-400 hover:text-accent-rose hover:bg-accent-rose/10 rounded-lg transition-colors disabled:opacity-50 disabled:cursor-not-allowed"
                       >
                         {deletingId === category.id ? (
                           <div className="animate-spin rounded-full h-4 w-4 border-b-2 border-accent-rose"></div>
                         ) : (
                           <Trash2 className="w-4 h-4" />
                         )}
                       </button>
                     </div>
                   </td>
                 </tr>
               )
             })}
           </tbody>
         </table>
       </div>
       ```

    3. Wrap keduanya (card + table) dalam satu kondisi yang sudah ada (bukan loading/empty).
       Struktur akhir dalam kondisi `filteredCategories.length > 0`:
       - `<div className="space-y-3 lg:hidden">` — card list (mobile)
