<objective>
## Goal
Redesign SidebarNav (desktop) dan BottomNav (mobile) menggunakan Framer aesthetic — canvas background, hairline borders, monochrome nav items dengan pill active state — menggantikan glass-panel slate theme lama dan memperbaiki broken `text-primary-400` active state.

## Purpose
Phase 07 membangun token foundation-nya. Phase 08 adalah first consumer nyata: navigation shell adalah elemen yang selalu terlihat di setiap halaman — jika nav masih glass/slate, seluruh app terasa inconsistent. Selain itu `text-primary-400` di SidebarNav sekarang broken (token dihapus) sehingga active state tidak tampil.

## Output
- `src/components/SidebarNav.jsx` — Framer sidebar: canvas bg, hairline border-r, pill active nav items, tight-tracking logo
- `src/components/BottomNav.jsx` — Framer bottom nav: surface-1 bg, hairline border-t (menggantikan glass)
- `.stitch/designs/sidebar-nav-reference.html` + `.png` — visual reference dari Stitch
</objective>
