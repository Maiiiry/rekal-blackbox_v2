<objective>
## Goal
Hapus batasan `max-w-lg` dari `.page-container` khusus di mode desktop dengan CSS context override — tanpa menyentuh satu halaman pun.

## Purpose
Phase 02 menambahkan sidebar, tapi konten masih sempit di tengah (`max-w-lg`) karena `.page-container` berlaku global. Phase ini membuat konten mengisi lebar penuh di desktop, sehingga phase 04-05 bisa redesign per halaman di atas fondasi yang benar.

## Output
- `WebLayout.jsx` — main element diberi class `desktop-content`
- `index.css` — override `.desktop-content .page-container` untuk desktop: no max-width, no centering, no BottomNav bottom padding
</objective>

<task type="auto">
  <name>Task 1: Tambah desktop-content class ke WebLayout + CSS override di index.css</name>
  <files>src/components/WebLayout.jsx, src/index.css</files>
  <action>
    **1. src/components/WebLayout.jsx**
    Tambah class `desktop-content` pada elemen `<main>`:
    ```jsx
    <main className="ml-60 flex-1 min-h-screen desktop-content">
    ```
    Tidak ada perubahan lain di WebLayout.

    **2. src/index.css**
    Tambah override di dalam `@layer components`, SETELAH definisi `.page-container` yang sudah ada (baris 65-68):
    ```css
    .desktop-content .page-container {
      @apply max-w-none mx-0 pb-8 px-8;
    }
    ```

    Override ini:
    - `max-w-none` — hapus batasan max-w-lg
    - `mx-0` — hapus centering mx-auto
    - `pb-8` — ganti pb-24 (BottomNav padding) dengan padding normal
    - `px-8` — sedikit lebih lebar dari mobile px-4 agar nyaman di desktop

    Pastikan override ditulis SETELAH `.page-container` original agar specificity CSS benar.
    Jangan ubah `.page-container` original sama sekali.
  </action>
  <verify>

    Konten harus melebar mengisi area kanan sidebar — tidak sempit di tengah lagi.
    Resize ke < 1024px: konten kembali max-w-lg terpusat.
  </verify>
  <done>AC-1, AC-2, AC-3 terpenuhi: desktop full-width, mobile tidak berubah, padding nyaman</done>
</task>
